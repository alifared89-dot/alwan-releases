# علوان — قواعد نشر صور الأجهزة (Public Release Safety)

هذا المجلد يحتوي على أدوات تشغيل وفحص **قديمة وقيد ترحيلها للمستودع الخاص**. وجودها هنا مؤقت للحفاظ على عمل GitHub Actions والتحقق من سلامة النشر، وليس دليلاً على أنها النسخة الأحدث من بوت البحث.

## قواعد التشغيل والنشر العامة

- **المصدر الوحيد للصور المنشورة:** [`device-media/device_media_manifest.json`](../../device-media/device_media_manifest.json) في فرع `main`. عدد الصور المنشورة لا يُستنتج من نتائج البحث أو تقارير المراجعة.
- **بيانات التوافق:** [`compatibility/manifest.json`](../../compatibility/manifest.json) والملفات المشار إليها منه هي الملفات التي يقرأها التطبيق. لا تغير روابطها أو صيغة البيانات دون اختبار عقد التوافق.
- **ملفات الوسائط:** `device-media/distribution.json` والـZIPs المنشورة محمية. لا تحذف أو تستبدل أياً منها بسبب تعديل في البوت.
- **الحماية الإلزامية:** راجع [`PROTECTED_PUBLISHING.md`](../../PROTECTED_PUBLISHING.md) و[`AGENTS.md`](../../AGENTS.md) و[`device-media/README.md`](../../device-media/README.md) قبل أي PR.
- **بوابة النشر:** يجب أن تنجح وظيفتا `compatibility-contract` و`media-integrity` مع الحفاظ على أسماء الوظائف نفسها؛ لا تحذف أدوات التحقق المرتبطة بهما أو تضعف شروطهما.
- **نشر الصور الجديدة:** المراجعة البشرية، رمز الموديل الدقيق، مصادر الإثبات وحقوق إعادة الاستخدام مطلوبة. `approved.json` ليس موافقة بحد ذاته إن لم تكن سجلات الاعتماد المكتملة موجودة؛ والنشر محمي بمسار PR وليس دفعاً مباشراً إلى `main`.
- **التقارير والبحوث:** المخرجات المؤقتة ونتائج الاكتشاف لا تعد نشرًا، ولا تمنح أي محادثة أو أداة صلاحية تعديل بيانات العملاء تلقائياً.
- **حماية التطبيق:** لا تعدّل `latest.json` أو روابط APK أو ملفات `compatibility/**` أو `device-media/**` كجزء من نقل أدوات البوت.

## حالة الانتقال

البوت المطوّر حالياً وأدوات البحث الداخلية والتوثيق التفصيلي محفوظة في مستودع خاص منفصل. بعض وظائف النشر والفحص الموجودة في هذا المستودع العام **ما زالت تستدعي أدوات هذا المجلد**. لذلك لا تُحذف أي ملفات تنفيذية أو اختبارية من هنا قبل أن يتوفر بديل محمي ويثبت نجاح اختبارات GitHub اللازمة.

هذا الملف وصف سلامة للنشر فقط، ولا يغير آلية التطبيق أو وظائف البوت.
